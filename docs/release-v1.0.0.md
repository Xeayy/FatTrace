# FatTrace v1.0.0

发布日期：2026-11-08

首个正式版本：面向 Windows 10/11 + NTFS 的本地磁盘增长追踪器。每日采集轻量快照，每周做全量对比，回答“哪里在长、长了多少、可能是什么”，但**永不删除、移动或清理用户文件**。

## 主要能力

- 基于 FileID 的快照对齐：新增、变大、变小、删除、move/rename 与目录归因。
- 75 条内置解释规则、20 个类别（缓存、日志、容器、开发产物、应用更新等），支持 `rules.yaml` 覆盖。
- 单文件离线 HTML 报告、只读本地 Web UI、日汇总、告警与自动周报。
- `fat setup` 首次引导、`fat tray` 托盘启动器、`fat serve --open` 直接打开面板。
- `fat doctor` 自检、保留策略、计划任务（错过后补跑，可仅交流电运行）。
- 标准用户即可运行；受保护目录体现为覆盖率与扫描错误，不影响其余数据。

## 真实数据与门禁

- 基线：快照 `#10`（2026-10-29 17:27）→ `#19`（2026-11-05 03:00），6.4 天，均为整卷 complete 快照。
- **原始 69 条规则：解释率 60.01%**（12.11 / 20.18 GiB），**未达 70% 门禁**，该结果保留为正式记录。
- 补 6 条通用规则（应用版本目录、Electron 资源、旧版本 exe、Git 对象、Python venv、单数 Download）后，同一数据重算 **88.07%**（17.78 / 20.18 GiB）。
- 以上两个数字必须分开表述：v1.0 的“补规则后达标”不是原始门禁直接通过。
- 卷级校验 7.35% WARN；残余未解释主要是少量应用主程序 exe。
- 首份真实周报生成于 2026-11-08；真实采集从 2026-10-29 起连续运行。

## 已知限制

- 便携 `fat.exe`，无安装器、无代码签名；首次运行可能触发 SmartScreen 提示。
- 标准用户权限下无法读取受保护目录；覆盖率约 99%，固定出现 3 个扫描错误。管理员运行可减少盲区，但不是必需。
- 不提供自动清理；`cleanup` 字段未实现。
- 受保护的系统数据（如卷影副本）对扫描不可见，卷级校验可能显示 WARN。
- AC-only 为默认：电池供电时不启动计划扫描；已经开始的扫描允许跑完，不会在切换电池时被终止。
- 计划任务以 `LeastPrivilege + InteractiveToken` 运行，与手动 `fat snap` 看到的文件范围一致。

## 安装与使用

1. 下载 `fat-1.0.0-windows-amd64.exe`（ARM64 机器选 `arm64`），按 `SHA256SUMS.txt` 校验。
2. 放到任意本地目录，运行 `fat.exe setup` 完成数据库、配置与扫描根设置。
3. 运行 `fat.exe tray` 常驻托盘，或 `fat.exe serve --open` 只开网页。
4. 首次只有一份快照时无法比较，等第二次快照后再看 diff/报告。
