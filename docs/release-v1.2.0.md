# FatTrace v1.2.0

发布日期：2026-11-11

未解释项浏览器 / 规则助手版本。把未解释增长变成可浏览、可搜索的清单，并提供半自动规则助手生成 `rules.yaml` 草稿；全程只读，草稿由用户确认后手动生效。核心扫描/diff/调度/数据库口径不变。

## 新增

- **未解释项浏览器**：SPA 新视图“未解释与规则”，分页/路径过滤/排序；内部保留按大小排序的未解释样本（上限 5000），公开 Top 50 与报告 JSON 不变。
- **规则助手**：选中未解释项预填规则表单，编辑 globs/类别/置信度；“预览命中”用真实匹配器估算命中文件数/字节/预计解释率并给出过宽/硬编码警告；“生成草稿”客户端拼出 `rules.yaml`，支持复制/下载。
- **只读 API**：`GET /api/unexplained`、`GET /api/rules/preview`、`GET /api/categories`；复用 diff 缓存，不新增写接口。

## 验证

- `go vet ./...` 与 `go test ./... -count=1` 全绿；新增聚合上限、预览、三个新接口的测试。
- 真实库 `#19→#20`：未解释 4,105 个 / 2.43 GiB / 解释率 26.38%；SPA 新视图截图核对正常。

## 门禁记录（沿用）

- 原始 69 条规则：`#10→#19` 解释率 **60.01%**，未达 70% 门禁。
- 补 6 条通用规则后同一数据：**88.07%**。
- 两个数字分开表述；v1.2.0 不改变该记录。

## 已知限制

- 预览只估算当前未解释样本，不预估对已解释项的影响；浏览样本上限 5000。
- 规则只贴标签、不改数字、不触发清理；草稿需用户确认，保存为 `<数据库目录>/rules.yaml` 并重启生效。
- 便携 exe，无安装器、无代码签名；正式图标仍暂缓（默认图标）。
- 标准用户覆盖率约 99%，固定 3 个扫描错误；不提供自动清理。
