# FatTrace v1.0.2

发布日期：2026-11-11

卷级差额归因版本。核心功能与 v1.0.1 相同，新增对“卷级校验 WARN”的归因说明：差额到底来自扫描看不见的系统保护区，还是文件级统计可能漏了数据。

## 新增

- **差额归因模型**：`VolumeCheck` 新增 `residual_alloc`（卷 Δ − 根 Δ）、`unscanned_delta_alloc`（扫描不可见区域 Δ）、`unexplained_alloc`（未解释差额）与 `cause`。
- **归因口径**：每次快照的“扫描不可见字节” = `volume_used − unique_alloc_bytes`，包含受保护目录、卷影副本、NTFS 元数据等；用两次快照的该值变化解释差额，剩余部分才视为需排查。
- **结论分类**：`within_tolerance` / `invisible_area`（不可见区域可解释）/ `mixed`（部分可解释）/ `file_level`（需排查）/ `skipped`。`ok` 语义不变，仍只表示是否在 2% 容差内。
- **终端**：`fat diff` 输出差额、扫描不可见 Δ、未解释量三行与 cause。
- **周报与 Web**：两周对比横幅按 cause 着色（不可见区域可解释为黄色，需排查为红色）；KPI 显示结论；“卷级校验与警告”面板新增差额、不可见 Δ、未解释差额三行。
- **API**：`/api/diff` 透出新字段，无接口破坏。

## 修复

- 负数字节格式化：`-143027552864 B` 现在显示为 `-133.20 GiB`，影响 diff、日汇总等所有负值尺寸输出。

## 已知限制

- 便携 `fat.exe`，无安装器、无代码签名，首次运行可能触发 SmartScreen。
- 标准用户无法读取受保护目录；覆盖率约 99%，固定出现 3 个扫描错误。
- 差额归因是**聚合估算**，只能说明差额与不可见空间整体变化吻合，不能定位具体保护目录或 VSS；FatTrace 不使用 VSS、不提权枚举。
- 不提供自动清理；`cleanup` 字段未实现。
- AC-only 默认：电池上不启动计划扫描；已经开始的扫描允许跑完。
