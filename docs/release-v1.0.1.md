# FatTrace v1.0.1

发布日期：2026-11-10

采集健康告警版本。核心功能与 v1.0.0 相同，新增对“扫描失败、连续失败、数据过期”的统一提示，让无人值守时的异常不再静默。

## 新增

- **统一健康模型**：按扫描根汇总最近完整快照、最近一次失败、连续失败次数与数据年龄。
- **`fat doctor`**：单次失败显示原因并警告；连续 2 次失败或数据超过阈值未更新则失败。
- **托盘**：tooltip 与右键菜单显示健康状态；启动时若已异常会弹出通知。
- **Web 状态页**：新增“采集健康”面板；任意页面在警告/异常时顶部显示横幅。
- **`fat maintain`**：日志新增 `health <root> level=... failures=... stale=... reason=...`，JSON 输出新增 `health` 字段。
- **可配置过期阈值**：`alerts.stale_hours`，默认 36 小时。
- **失败原因可追溯**：例如“进程在完成前退出或被系统终止，未写入文件记录”，并指向 `logs/maintain.log`。

## 已知限制

- 便携 `fat.exe`，无安装器、无代码签名，首次运行可能触发 SmartScreen。
- 标准用户无法读取受保护目录；覆盖率约 99%，固定出现 3 个扫描错误。
- 不提供自动清理；`cleanup` 字段未实现。
- 受保护的系统数据（如卷影副本）对扫描不可见，卷级校验可能 WARN。
- AC-only 默认：电池上不启动计划扫描；已经开始的扫描允许跑完。
