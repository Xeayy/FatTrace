## 1. 项目是什么

FatTrace 是面向 Windows 10/11 + NTFS 的本地磁盘增长追踪器：

- 每日采集文件系统快照，每周做全量对比。
- 用 FileID 对齐文件/目录，识别新增、变大、变小、删除、move/rename，并做目录归因。
- 用规则解释增长来源，输出单文件 HTML 报告和只读本地 Web UI。
- 只回答“哪里在长、长了多少、可能是什么”，**不删除、不移动、不清理用户文件**。

项目根目录：`D:\FatTraceDemo\FatTrace`

## 6. 运行方式与计划任务

- **不是常驻服务**，没有 Windows 服务、没有开机自启、没有网络请求/遥测。
- `FatTrace-Daily`：每天 03:00；`FatTrace-Weekly`：周日 04:00。
- 任务只运行约 1 分钟，完成扫描/汇总/告警/周报后退出。
- 任务为 `LeastPrivilege + InteractiveToken`，需要用户登录；`StartWhenAvailable=true`，错过会在可用时补跑，所以实际时间可能是 10:40、12:25 等。
- AC-only：`DisallowStartIfOnBatteries=true`、`StopIfGoingOnBatteries=false`——电池上不启动新扫描，已开始的扫描允许跑完。
- 当前 doctor：任务检查 healthy；整体通常 `11 ok / 1 warn / 0 fail`，唯一常见警告是快照新鲜度。
- 托盘/Web 只在双击快捷方式或运行 `fat tray` / `fat serve` 时存在；关闭即停止。
- 桌面 `FatTrace.lnk`（`D:\Demo\Desktop`）已改指向 `fatgui.exe --db "D:\FatTraceDemo\.cache\fattrace\fattrace.db"`（无闪窗，用户确认）；计划任务仍用 `fat.exe`。

## 7. 安全与硬性约束

- 所有工具、缓存、构建产物必须位于 `D:\FatTraceDemo`。
- GitHub 仓库必须私有（`Xeayy/FatTrace`，`master`）。
- **GitHub token 绝不能打印或持久化到远端 URL/配置**。
- 按里程碑交付；**单词“git”即授权提交/推送**；未出现“git”不得提交/推送。
- 系统级改动（计划任务、提权、自启、ACL、安装器）必须先获得用户确认。
- 不自动清理用户文件；删除只发生在 FatTrace 自己的历史数据库（`fat prune`）。
- 旧 OAuth token 曾在对话中泄露；2026-11-08 通过 GitHub `POST /credentials/revoke` 吊销并用旧 token 请求 `/user` 验证 401。2026-11-10 用户已在浏览器重新登录，推送恢复。不要再次输出/保存 token。
- 非目标：自动清理、实时监控、网络盘/非 NTFS、云同步、安装器/提权/签名（M8b 已取消）。

## 8. 已知限制与坑

- 无安装器、无代码签名；首次运行可能触发 SmartScreen。
- 标准用户无法读取受保护目录；覆盖率约 99%，固定 3 个扫描错误。
- `System Volume Information` / 卷影副本对扫描不可见，卷级校验可能 WARN；2026-11-11 起会按“扫描不可见区域变化”归因，但只能整体估算，不能定位具体保护目录。
- 不提供自动清理；`cleanup` 字段未实现。
- `fat.exe tray` 直接双击仍会闪控制台；改用 `fatgui.exe` 无闪窗。正式图标已定案并嵌入（v1.3.0，卷尺量磁盘、深色圆角底）；16px 为简化轮廓。
- 计划任务依赖登录和 AC；机器休眠/关机时会延迟补跑。
- CI 吞吐测试曾两次因共享 runner 抖动失败；门槛已改为本地 80k、CI 50k，只保留数量级回归信号。
- GitHub 推送偶尔出现 `curl 52 Empty reply`；先推 tag、再推 master 的重试方式曾成功。
- `--max-depth` 快照不更新基线是刻意保留的诊断语义。

## 10. 关键决策与教训

- 门禁周内不改规则，避免污染解释率；原始失败必须保留，补规则结果单独标注。
- 补规则只加通用模式，不为单个应用硬编码（避免解释率虚高）。
- 解释率分母是正向增长 `growth_bytes`，不是净增长；应用更新“新版写入、旧版删除”会天然压低解释率。
- 删除 PBZ 等大文件会造成大幅负增长，属真实事件，不是扫描错误。
- 计划任务旧 XML 的 `StopIfGoingOnBatteries=true` 会中止扫描；已改为只禁止电池启动、不终止进行中扫描。
- 泄露 token 用 GitHub 官方无认证撤销接口处理；凭据不落盘、不打印。
- CI 性能门槛不能贴着实测值设置，否则共享 runner 抖动会误报。
- 卷级差额只做聚合归因：扫描不可见字节包含所有不可见空间，不能把它当成 VSS 实际大小，也不猜测具体保护目录。
- 用户是产品负责人，只给方向；汇报先讲产品状态与待决项，技术细节按需展开；用户偏好双击即用的可视化入口。
